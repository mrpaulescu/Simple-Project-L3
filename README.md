# Simple Webpage

A clean and modern HTML/CSS webpage with a responsive layout and an integrated CSS Grid image gallery.

## Features

- Responsive navigation header (`Home`, `About`, `Gallery`, `Contact`)
- Four main sections (`#home`, `#about`, `#galerie`, `#contact`)
- Responsive 3-column image gallery (`#galerie`) built with modern CSS Grid and a `1rem` gap (no floats)
- Mobile-friendly gallery layout that adapts to a single column on screens smaller than `600px`
- Modern styling with hover effects, clean typography, and card-based sections
- Footer section

## Files

- `index.html` - Main HTML5 semantic structure including the gallery section
- `styles.css` - Stylesheet using Flexbox, CSS Grid, and responsive media queries
- `README.md` - Project documentation

## How to Use

1. Place `index.html` and `styles.css` in the same directory.
2. Open `index.html` in your web browser.
3. Use the navigation links in the header to jump between sections, and resize the browser window below `600px` to see the responsive single-column gallery layout.

## Technologies

- HTML5
- CSS3 (Flexbox & CSS Grid)
